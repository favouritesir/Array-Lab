## 🌟 পরিচিতি

**অ্যারে-ল্যাব (Array-Lab)** হলো কোনো প্রকার এক্সটার্নাল ডিপেন্ডেন্সি ছাড়া একটি সম্পূর্ণ ও স্বয়ংসম্পূর্ণ সিঙ্গেল-ফাইল ইন্টারঅ্যাক্টিভ প্ল্যাটফর্ম। এটি অ্যারে ডেটা স্ট্রাকচার এবং অ্যালগরিদম শেখা, ভিজুয়ালাইজ করা, ডিজাইন করা এবং গবেষণার জন্য তৈরি করা হয়েছে। 

এতে রয়েছে কার্ডের ফিজিক্স-বেসড ৩ডি আর্কিং সোয়াপ অ্যানিমেশন, মাল্টি-পয়েন্টার আইসোলেশন, লাইভ ব্রেকপয়েন্ট, সামনে ও পিছনে টাইম-ট্রাভেল স্টেপিং, ভাসমান স্টিকি নোটস, ইন-স্ট্রিম ক্রোম স্টাইল দেবটুলস জাভাস্ক্রিপ্ট REPL কনসোল এবং মানুষের চিন্তা ও অ্যাকশন ট্র্যাক করার বিশেষ সেশন রেকর্ডার।

বাবল সর্ট, কুইক সর্ট, বাইনারি সার্চ, টু-পয়েন্টার, স্লাইডিং উইন্ডো কিংবা ক্লাউড মার্জ সর্টের মতো উদ্ভাবনী অ্যালগরিদম যাই হোক না কেন—**Array-Lab** প্রতিটি মেমরি পরিবর্তনের ভেতরকার চিত্র চোখের সামনে নিখুঁতভাবে ফুটিয়ে তোলে।

## ✨ প্রধান সুবিধাসমূহ ও ক্ষমতা

### ১. 🤹 ইন্টারঅ্যাক্টিভ অ্যারে ক্যানভাস স্টেজ
- **ফিজিক্যাল গ্লাইডিং কার্ডস**: সোয়াপ করার সময় কার্ডগুলো শূন্যে ধনুকের মতো ৩ডি আর্চে উড়ে গিয়ে একে অপরকে ক্রস করে স্লটে পৌঁছায় এবং ল্যান্ডিং পালস দেয়।
- **স্বতন্ত্র স্পিড কন্ট্রোল**: কোড এক্সিকিউশন স্টেপের গতি (`৪০ms - ১২০০ms`) এবং সোয়াপ গ্লাইডের অ্যানিমেশন গতির (`৮০ms - ৯০০ms`) জন্য আলাদা স্লাইডার।
- **ড্র্যাগ অ্যান্ড ড্রপ ফ্রি রিয়্যারেঞ্জ**: মাউস দিয়ে সরাসরি কার্ড ড্র্যাগ করে অদল-বদল করা এবং কাস্টম অ্যারে জেনারেটর স্টুডিওর সাহায্যে যেকোনো ডেটা লোড করার সুবিধা।

### ২. 🎯 মাল্টি-পয়েন্টার আর্কিটেকচার ও স্কোপ আইসোলেশন
- **কোড-ড্রাইভেন পয়েন্টার ট্র্যাকিং**: `i`, `j`, `left`, `right`, `mid`, `minIdx` ইত্যাদি পয়েন্টার স্বয়ংক্রিয়ভাবে কার্ডের উপরে স্ন্যাপ হয়।
- **স্মার্ট স্কোপ আইসোলেশন (`fn::var`)**: রিকার্সিভ ফাংশনে প্রতিটি লোকাল স্কোপের পয়েন্টার আলাদাভাবে সংরক্ষিত থাকে।
- **কার্ডের উপর জিরো ওভারল্যাপ**: একই ইনডেক্সে একাধিক পয়েন্টার অবস্থান করলেও কার্ডের ভেতরের লেখা বা সংখ্যা কখনো ঢেকে যায় না।

### ৩. ⏪ টাইম-ট্রাভেল স্টেপিং (সামনে ও পিছনে)
- **মাইক্রো এক্সিকিউশন স্ন্যাপশট**: যেকোনো মুহূর্তে অ্যালগরিদমের এক স্টেপ সামনে (`⏭️`) অথবা পিছনে (`⏮️`) টাইম-ট্রাভেল করা যায়।
- **রিভার্স ফিজিক্যাল সোয়াপ**: পিছনের স্টেপে যাওয়ার সময় কার্ডগুলো রিভার্স আর্কিং গতিতে স্বয়ংক্রিয়ভাবে তাদের আগের স্লটে ফিরে যায়।
- **রিডু স্ট্যাক সাপোর্ট**: যেকোনো এক্সিকিউশন ট্রেইলের মাঝে সামনে-পিছনে নির্বিঘ্নে ট্রাভেল করা যায়।

### ৪. 💻 ইন-স্ট্রিম রিয়েল ক্রোম দেবটুলস কনসোল REPL
- **একীভূত লগ স্ট্রিম**: কনসোলের ইনপুট প্রম্পট (`>`) আলাদা নিচে নয়, বরং ক্রোম দেবটুলসের মতোই স্ক্রলেবল লগ লাইনের ভেতরে একদম নিচে অবস্থান করে।
- **গ্লোবাল উইন্ডো স্কোপ পারসিস্টেন্স**: কনসোলে ভ্যারিয়েবল ডিক্লেয়ার করলে বা ফাংশন বানালে তা মেমরিতে সংরক্ষিত থাকে।
- **বিল্ট-ইন গ্লোবাল কমান্ডস**:
  - `arr` : বর্তমান লাইভ অ্যারে দেখা।
  - `state` : পয়েন্টার, স্পিড ও স্টেটের বিশদ বিবরণ।
  - `swap(i, j)` : সরাসরি এনিমেশন সহ দুটি ইনডেক্স সোয়াপ করা।
  - `console.table(arr)` : টেবিল ভিউতে অ্যারের মান দেখা।
  - `clear()` বা `cls` : কনসোল স্ক্রিন ক্লিয়ার করা।
  - `$_` : সর্বশেষ কমান্ডের ফলাফল রিটার্ন করা।
  - ক্রোম ব্রাউজারের মতোই `< undefined` সহ সকল রিটার্ন ভ্যালু লগ করার সুবিধা।

### ৫. ⚡ জিরো-বয়লারপ্লেট সাধারণ কোড এক্সিকিউশন
- কোনো প্রকার জটিল হেল্পার ফাংশন লেখা ছাড়াই সরাসরি স্ট্যান্ডার্ড জাভাস্ক্রিপ্ট কোড লিখুন:
  ```javascript
  let n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        let temp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = temp;
      }
    }
  }
  ```
- ব্যাকগ্রাউন্ড AST ট্রান্সপাইলার স্বয়ংক্রিয়ভাবে লুপ, কম্প্যারিজন, পয়েন্টার এবং ৩-লাইনের `temp` সোয়াপ কিংবা আধুনিক ES6 `[arr[i], arr[j]] = [arr[j], arr[i]]` শনাক্ত করে নেয়।

### ৬. 📝 ড্র্যাগেবল স্টিকি নোটস ও রিসার্চ ক্যানভাস
- ক্যানভাসে যেকোনো স্থানে স্টিকি নোট তৈরি করে গবেষণার পর্যবেক্ষণ বা সমীকরণ লিখে রাখা যায়।
- প্রজেক্ট সেভ করার সাথে সাথে স্টিকি নোটের অবস্থান ও লেখাও সংরক্ষিত থাকে।

### ৭. 🎬 থিংকিং ও অ্যাকশন সেশন রেকর্ডার
- অ্যালগরিদম নিয়ে ভাবার সময় কার্ডের মুভমেন্ট, পয়েন্টার নড়াচড়া ও কোড টেস্টের পুরো সেশন রেকর্ড করা যায়।
- যেকোনো সময় সেশনটি এক্সপোর্ট করে পরবর্তীতে প্লে-ব্যাক করে দেখা যায়।
